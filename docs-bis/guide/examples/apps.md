# Apps

Perhaps the best place to look for sample code is within real apps! If you know others that aren't in this list, feel free [to open a PR](https://github.com/NoelDeMartin/soukai/pulls).

## Media Kraken

[Media Kraken](https://noeldemartin.github.io/media-kraken/) is a media tracker, and it's being rewritten using this version of Soukai with [Aerogel](https://aerogel.js.org), a framework built with Soukai at its core. If you're looking for an actual app using the latest features (such as local-first synchronization), this is the codebase for you.
