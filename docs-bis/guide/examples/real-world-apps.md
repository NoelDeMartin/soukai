# Real-World Apps

Perhaps the best place to look for sample code is within real apps! If you know others that aren't in this list, feel free [to open a PR](https://github.com/NoelDeMartin/soukai/pulls).

## Media Kraken

[Media Kraken](https://noeldemartin.github.io/media-kraken/) is a media tracker, and it's being rewritten using this version of Soukai with [Aerogel](https://aerogel.js.org), a framework built with Soukai at its core.

The rewrite is still in progress, so you'll find it in the [`aerogel` branch](https://github.com/NoelDeMartin/media-kraken/tree/aerogel). If you're looking for an actual app using the latest features (such as local-first synchronization), this is the codebase for you.

## Umai

> [!WARNING] ⚠️ Using a previous version
> Umai hasn't been migrated to `soukai-bis` yet, so its codebase uses the previous version of Soukai. Check out the [Upgrade Guide](../getting-started/upgrade-guide.md) to see what has changed.

[Umai](https://umai.noeldemartin.com/) is a local-first recipes manager built with Aerogel. It's the most complete app built with the previous version of Soukai, so it's a good place to look at how a full-featured app is structured.

## Focus

> [!WARNING] ⚠️ Using a previous version
> Focus hasn't been migrated to `soukai-bis` yet, so its codebase uses the previous version of Soukai. Check out the [Upgrade Guide](../getting-started/upgrade-guide.md) to see what has changed.

[Focus](https://focus.noeldemartin.com/) is the OG, the first app developed with Soukai. It has since been rewritten using Aerogel as well.

## Ramen

> [!WARNING] ⚠️ Using a previous version
> Ramen hasn't been migrated to `soukai-bis` yet, so its codebase uses the previous version of Soukai. Check out the [Upgrade Guide](../getting-started/upgrade-guide.md) to see what has changed.

[Ramen](https://ramen.noeldemartin.com/) is, quite possibly, the simplest app using Soukai out there. It may even be a stretch to call it "a real app", but it's the perfect place to look at how the library can be used in a codebase that is built with production in mind.
